# IP Address Checker 🖥️

A simple Python-based tool designed to validate IP addresses and identify their network information. This project uses Python's built-in `ipaddress` module to analyze IPv4 and IPv6 addresses.

## Features

- **IP Address Validation** – Checks whether an IP address is valid.
- **IP Version Detection** – Identifies whether the address uses IPv4 or IPv6.
- **IP Classification** – Determines whether an IP address is Private or Public.
- **Loopback Detection** – Identifies loopback addresses.
- **Multicast Detection** – Detects multicast addresses.
- **Error Handling** – Displays an error message when an invalid IP address is entered.

## Technologies Used

- Python 3
- ipaddress (Built-in Python Module)

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/USERNAME/python-ip-address-checker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-ip-address-checker
   ```

3. Run the application:

   ```bash
   python main.py
   ```
